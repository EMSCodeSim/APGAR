# EMSCodeSim — APGAR

Interactive newborn APGAR trainer for EMS and clinical education.

Open `index.html` in a browser. Adjust **Appearance**, **Pulse**, **Grimace**, **Activity**, and **Respiration** (each 0–2) and watch the baby’s color, tone, breathing, heart-rate cue, and reflex response update live.

## Features

- Full five-component APGAR with live total and brief interpretation
- Visual cues for central cyanosis, acrocyanosis, chest rise, limb tone, and pulse
- Stimulate button to demonstrate grimace / cry response
- Distressed, moderate, and vigorous demo scenarios
- Keyboard-focusable controls and `prefers-reduced-motion` support

## Notes

This is a recognition/practice aid, not a timing or documentation tool. APGAR is typically scored at 1 and 5 minutes of life.
